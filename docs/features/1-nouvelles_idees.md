#Tache 1
J'aimerais pouvoir savoir combien je dois verser de montant sur chaque compte pour un mois. POur le moment j'ai à peu près ça sur le dashboard mensuel (Récapitulatif -> Filtre Compte), mais y'a une notion qui manque, car des revenus tombes sur un compte courant par example et des charges aussi, 
et cela m'indique combien je dois avoir sur ce compte, mais il manque une notion de transfert de quel compte à quel compte je dois transférer. Il serait bien de faire une sorte de tree (voir composant primeng) pour voir par example le compte courant doit transférer 100chf sur le compte épargne, 50chf sur le compte vacances, et que depuis le compte privé sur le compte bébé de 50chf, etc.
Analyse et voir l'hypothèse de renseigner pour chaque poste le compte "à partir" et le compte actuel déjà dans le modèle est le compte de destination. Si le compte est le même entre "a partir" et "destination", alors aucun transfert n'est compatibilisé dans le tree.
